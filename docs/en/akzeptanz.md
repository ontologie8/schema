# Acceptance criteria

The complete P0–P6 scope lives in the [roadmap](../../roadmap/en/personen-nachlass-roadmap.md).

| ID | Criterion |
| --- | --- |
| AC-01 | Preserve all ideas, house/car/annual-share cases and both death orders. |
| AC-02 | Document phases, dependencies, verifiable outcomes and open design choices. |
| AC-03 | Distinguish JSON Schema, NetworkX, RDF/Turtle/SHACL and graph database gate; one leading model. |
| AC-04 | No production mandate data in Git; evidenced relationships, deterministic computation and professional review. |
| AC-05 | Verify language parity, Gantt links and appropriate remote CI. |
| AC-06 | One person with multiple temporal roles; office does not imply ownership. |
| AC-07 | Separate company assets, private shares, loans and guarantees; no double-counting. |
| AC-08 | Distinguish death/incapacity/end of office, share succession and office/representation succession; no automatic permissions. |
| AC-09 | Family, holding and representation views identify date, sources and unresolved facts. |

These criteria define the validation goals for the planned implementation. See the [project board](projekt.md).
